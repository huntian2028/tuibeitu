# 推背图 TuiBeitu

> 推背图是中华预言第一图，藏往知来、推演未来。本项目借其名，以 three.js 推演进程走向、预测未来图景，把时间轴上的事件织成可观测的立体长卷。

基于 three.js 的 3D 关系演示系统，以西游记全景为样本，深挖事件脉络、推演进程走向、预测未来图景，让复杂关系立体可见。
